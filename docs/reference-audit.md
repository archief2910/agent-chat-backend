- Empty state, new chat, and the first message

- Composer: multiline input, send, stop, interrupt, plan mode, attachment and media controls, model status
- Streaming text, thinking, and the status sequence
- Tool cards for pending, running, completed, failed, and cancelled
- Approval overlays and what happens when one expires
- Generated image, video, and audio, including the artifact panel
- Credit balance, an insufficient-credit message, and the ledger
- Reload and chat-switch while a run is active
- Desktop and a narrow mobile width

If something in the product looks wrong, write it here for the reviewer instead of redesigning it.
